# 잠깐 집중

20분 집중과 5분 휴식, 떠오른 생각을 맡겨두는 빠른 메모. React 19 + TypeScript + Vite로 만든 한국어 웹앱입니다. 로그인·서버·외부 API 없이 사용합니다.

## 실행

```sh
cd /workspace/test
npm ci
npm run dev
```

개발 서버 기본 포트는 5173입니다. 배포용 정적 파일은 `npm run build` 실행 후 `dist/`에 생성됩니다. HTTPS 또는 localhost에서 사용할 것을 권장합니다(탭 간 Web Locks 및 브라우저 알림).

## 검증

```sh
npm run typecheck
npm run build
npm test
npx playwright test
```

Playwright 설정은 이 환경의 `/usr/bin/chromium`을 사용합니다. 다른 환경에서는 `npx playwright install chromium` 실행 후 `playwright.config.ts`의 `executablePath`를 해당 설치에 맞게 변경하거나 생략하세요.

- 단위 테스트: 종료 시각 계산, 전환과 자동 시작 조합, 일시정지/재개, 만료 복원, 중복 기록, 자정 날짜 변경, 수동 종료 제외, 시간 검증, 회차 메모 안내.
- 브라우저 테스트: 메모 CRUD/취소/분류/완료/다음 목표, 한국어 조합 이벤트, 단축키, 새로고침, 동시 탭, 모바일 오버플로, 손상 데이터, 가상 시간 전환, 알림 거절, 저장 실패.
- 실제 운영체제 한국어 IME, 알림 수신 및 알림음 청취는 자동 테스트로 검증하지 않습니다.

## 구성

- `src/model.ts`: UI와 분리한 순수 타이머 전이·오늘의 기록 계산.
- `src/storage.ts`: 저장 데이터 검증과 읽기/쓰기 실패 처리.
- `src/TimerPanel.tsx`: 원형 진행률과 타이머 조작 화면.
- `src/QuickNote.tsx`: 빠른 메모 입력 및 조합 중 Enter 보호.
- `src/main.tsx`: 탭 간 잠금·동기화, 앱 조합, 메모 관리와 설정.

종료 시각으로 시간을 계산하고, 회차 ID로 완료 기록을 구분합니다. Web Locks 지원 환경에서는 localStorage 변경을 탭 간 직렬화합니다. 복귀 시 만료된 회차는 한 번만 기록하며 다음 회차를 자동으로 누적하지 않습니다. 오늘은 기기의 현지 날짜, 기록 날짜는 해당 회차의 종료 시각을 기준으로 합니다.

모든 데이터는 `jamkkan-focus-v1` localStorage에 저장됩니다. 기기 간 동기화는 없으며, 브라우저 데이터 삭제 시 소실됩니다. 저장소 이용이 거절되거나 가득 찬 경우 현재 탭에서 사용을 이어갈 수 있지만 영구 저장은 보장하지 않습니다. 삭제 취소는 8초간 가능합니다. 브라우저가 닫힌 상태의 알림과 모바일 백그라운드 소리는 보장하지 않습니다. Web Locks 미지원 브라우저의 동시 편집 충돌 방지는 제한적입니다.

테스트는 격리된 브라우저 저장소와 가상 시간을 사용하므로 앱의 실제 기본값(20분/5분)을 바꾸지 않습니다. 기존 `test.txt`는 유지했습니다.
